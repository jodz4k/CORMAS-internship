## Project Description

Serious games are essential tools in the participatory modeling approach, as they directly and playfully engage local stakeholders. These games facilitate idea-sharing, discussion, and collective decision-making in complex contexts, particularly in the Global South. However, facilitating, observing, and collecting data during these games remain time-consuming and demanding processes, often requiring specialized digital tools whose development itself takes significant time—especially when starting from scratch.

The core idea of this project is to create a **generic software solution** that supports the design, implementation, and analysis of serious games by adapting [Cormas](https://cormas.org), the agent-based participatory modeling platform developed by the SENS research unit. The project aims to develop a Cormas user interface that allows direct interaction with simulation agents via a smartphone. Each serious game could then be conceptualized as an agent-based model in which players themselves act as active agents.

This approach stands out through its innovative and integrative nature, built upon:

1. **Years of experience** within our team in developing serious games such as ReHab and ButorStar, which have gained a user community beyond academia, as well as the more recent Dukunú Molê, which originated from a request by the NGO BirdLife International.
2. **Generalizing an existing framework** (Cormas) to make it adaptable to various serious games, thereby reducing the costs and time required to develop specific solutions for each game.
3. **Integrating emerging technologies**, particularly through a connection with the TOrHs project, funded by CIRAD, which is developing smart game boards capable of automatically recognizing the pieces manipulated by players.

From a scientific perspective, this project advances participatory modeling tools by exploring **a new paradigm of human-machine collaboration**, where serious games become fully interactive models. From a technological perspective, it aligns with the growing trend of combining digital models with tangible interfaces, addressing the needs of researchers and practitioners in visualization, analysis, and facilitation.

This innovative project places our team at the forefront of serious games in participatory modeling. It establishes a solid foundation for future collaborations and broader applications across various fields, including natural resource management, territorial planning, and participatory education.
